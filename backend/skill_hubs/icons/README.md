# SkillHub 来源图标

图标取自各来源官网提供的站点图标，作为来源身份标识使用，保留原图。
由 `_icons.py` 通过 `data:image/png;base64,...` 返回，避免前端访问外部图床，
也无需为前后端分离部署增加静态资源地址配置。
